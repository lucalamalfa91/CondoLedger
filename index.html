Scarica il file calendario

Il file .ics contiene le rate residue con il promemoria impostato.

iPhone/iPad con Safari: si apre subito la schermata "Aggiungi tutti" di Calendario.

iPhone/iPad con Chrome: Chrome scarica sempre il file senza aprirlo (non dipende da questa app). Tocca l'avviso di download in basso, oppure apri l'app File → Scaricati, e tocca il file .ics: si aprirà la schermata di Calendario per confermare l'aggiunta.

Mac: apri il file scaricato con doppio clic: si apre l'app Calendario con gli eventi pronti da aggiungere.

Google Calendar/Gmail: vai su calendar.google.com → icona ingranaggio → Impostazioni → Importa e esporta → scegli il file .ics scaricato → Importa.

Se cambiano le rate (nuovo conguaglio, nuovo versamento), riapri questo wizard e riscarica il file: andrà reimportato per aggiornare gli eventi.
